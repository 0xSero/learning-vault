# Learning Vault — Home

A progressive-disclosure wiki of what this agent taught in the session of 2026-08-19: the God-and-Jesus speech corpus, the thread of God, the sacrifice thread, the Son of man, Methodism, and the methods behind it all.

> [!abstract] How to use this vault
> Every note follows the same disclosure protocol:
> 1. **TL;DR** — the whole note in one paragraph. Read only this if you're in a hurry.
> 2. **Body** — the working level. Enough to use the idea.
> 3. **Go deeper** — wikilinks to the next layer down. This is how you research: follow the links one layer at a time, never skip two.
> 4. **Sources** — external anchors (Wikipedia, data, books) to verify or extend.
>
> Navigate: start at the layer that matches your question. Primitives for vocabulary, Research for the deep dives, Applied for doing things with it.
