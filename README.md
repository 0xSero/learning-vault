# Learning Vault

Obsidian vault. The teaching wiki lives on the **`learning`** branch (checked out by default).

- `main` — scaffold only: `skills/` (kepano/obsidian-skills reference) + vault config.
- `learning` — scaffold + the full wiki: `LEARNING.md` (home/MOC) and the four layers
  `01-primitives/`, `02-research/`, `03-applied/`, `04-sources/`.

Branches are local-only; there is no remote for this vault.

Skills reference: https://github.com/kepano/obsidian-skills
